Copies of each agency source, cut to a few records, in each source's own format and field names
(as read from the sources in November 2026), for tools/test_load_agencies.py.

- fr_agencies.json: federalregister.gov/api/v1/agencies.json
- plum.csv: escs.opm.gov/escs-net/api/pbpub/download-data (OPM's PLUM data)
- usas_*.json: api.usaspending.gov/api/v2 (budgetary_resources, object_class, budget_function, spending_by_category/recipient)
- gao_reports.xml: gao.gov/rss/reports.xml
- fr_yearly.json, fr_rules.json: federalregister.gov/api/v1/documents (facets/yearly, documents.json)
